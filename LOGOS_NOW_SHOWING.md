## 🔧 **Customization Available**

Want to adjust logos? Easy changes possible:

**Resize:** Change className
```tsx
<CLSELogo className="h-40" />  // Larger
```

**Colors:** Modify SVG fill values
```tsx
fill="#E63946"   // Red
fill="#332470"   // Purple
fill="#2D5016"   // Green
```

**Layout:** Change flex/spacing
```tsx
<div className="flex gap-8">  // Adjust spacing
  <CLSELogo />
  <KGiSLLogo />
</div>
```
